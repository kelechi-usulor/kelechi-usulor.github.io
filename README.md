## 🌍 About Me
I'm an ethical hacker and bug bounty hunter based in Lagos, Nigeria. I focus on web application penetration testing and hunt for vulnerabilities on platforms like HackerOne and Bugcrowd. I also build clean, secure front-ends and test them with a Software Quality Assurance mindset, so I understand how bugs get shipped and how to stop them.

## ✨ Features
* **Dark / Light theme toggle** that follows the visitor's system preference and remembers their choice.
* **Fully responsive**, with a mobile-friendly navigation menu.
* **Smooth scroll-reveal animations** that respect reduced-motion settings.
* **SEO-ready**, with descriptive meta tags and Open Graph data.
* **Security toolkit and methodology** sections covering how I test and the tools I use.

## 🛠️ Built With
Intentionally built without frameworks to show strong frontend fundamentals:
* **HTML5:** Semantic markup and accessibility best practices.
* **CSS3:** Custom properties for theming, Grid and Flexbox layouts, and a mobile-first approach.
* **Vanilla JavaScript:** Theme switching, the mobile menu, and scroll animations.
* **Git & GitHub:** Version control, with deployment through GitHub Pages.
