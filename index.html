About Me

I'm a security researcher who hunts for vulnerabilities on bug bounty platforms like HackerOne and Bugcrowd, with a focus on web applications and APIs. I think like an attacker, but I report like an engineer: clear steps to reproduce, real impact, and practical fixes.

Because I also write code and do Software Quality Assurance, I understand how bugs get shipped, and how to help teams stop shipping them. I'm currently open to bug bounty collaborations, pentest engagements and web development work.
